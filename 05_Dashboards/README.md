# 📈 Dashboards

Esta pasta contém os dashboards desenvolvidos para visualização e acompanhamento dos dados do Projeto Agro Intelligence.

Os dashboards terão como objetivo transformar dados em informações visuais que facilitem a interpretação dos resultados e o apoio à tomada de decisões.

Serão utilizados, conforme a evolução do projeto:

- 📊 Gráficos e indicadores
- 🌱 Dados relacionados à produção
- 🌡️ Condições ambientais
- 💧 Informações sobre irrigação
- 📈 Indicadores de desempenho
- 🤖 Resultados das análises e modelos de Inteligência Artificial
