# 📊 Datasets

Esta pasta contém os conjuntos de dados utilizados no Projeto Agro Intelligence.

Os dados poderão ser utilizados para:

- 📈 Análise exploratória
- 🌱 Monitoramento da produção
- 🌡️ Análise de condições ambientais
- 💧 Controle e análise da irrigação
- 🐛 Identificação de possíveis problemas
- 🤖 Treinamento e avaliação de modelos de Machine Learning

Inicialmente serão utilizados dados simulados para desenvolvimento e testes.

Conforme o projeto evoluir, poderão ser incorporados dados reais, respeitando as fontes, licenças e condições de uso dos dados.
